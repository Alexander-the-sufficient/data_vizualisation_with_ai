- **What makes it "interactive" (beyond hover/zoom)**:
  1. **Selection** — click any country path; the GeoJSON Feature is written to a `Mutable selectedCountry`, and the country renders with a `heritageRedDark` outline.
  2. **Filtering (year)** — two-handle range via `Inputs.form({start: range, end: range})` on years 1980–2025; drives `filtered` and the year strip's foreground bars.
  3. **Filtering (magnitude)** — `Inputs.range([5.0, 7.5], step 0.1)`; drives `filtered`.

  5. **Encoding remap (preset zoom)** — four "Zoom to" buttons (World / Ring of Fire / Mediterranean / Andes); each preset is a `d3.zoomIdentity.translate(...).scale(...)` to a fixed center+scale. Replaces v2's projection-rotation dropdown.
  6. **Details on demand** — top-5 detail panel reading `selectedCountry` ∩ filter window (place, magnitude with type, depth km, ISO date, link to the canonical USGS event page).
  7. **Reset (reversibility)** — `Inputs.button` with a reduce that writes defaults back to year/magnitude controls, sets the preset to "world", and clears `selectedCountry`.
  8. **Linked event pin (v11)** — clicking any row in the country detail table writes a `Mutable selectedEvent` and draws a heritage-red ring + white halo on the main map at that event's projected position; the same event in the inset map switches from heritage-red to heritage-red-dark fill with a thicker stroke; the row gets a heritage-red left border + tinted background. Re-clicking the active row clears the pin (toggle); clicking a different country auto-clears any stale pin in `setSelectedCountry`. Counter-scaled with `r / sqrt(k)` in the zoom handler so the ring stays a fixed on-screen size from world view to k=32.

- **Which chart this documents**: US Treasury yield curve (10Y − 2Y spread) as a recession leading indicator, 1976–2026.
- **Data sources**: FRED (Federal Reserve Bank of St. Louis) — four series, downloaded via the project's API helper at `data/task_13/fetch_fred.R` (reads the `FRED_API_KEY` from the project-root `.env`, calls `https://api.stlouisfed.org/fred/series/observations`, writes a tidy CSV per series to `data/task_13/`):
